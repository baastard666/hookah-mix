# v0.2.7 — Tobacco Product Profile Registry Foundation

Добавлен независимый read-only реестр семи производителей и девяти линеек с категориальными strength, heat resistance и leaf types, evidence, confidence, aliases и наследованием. Публичный query API возвращает замороженные копии; адаптер принимает plain Flavor-like object. Добавлены 28 unit-тестов и `verify:tobacco-profile`.

Registry не подключён к текущим движкам, Mix Analysis Service, UI или PostgreSQL. Формулы анализа, Prisma schema, миграции и seed не менялись. Стартовые значения являются осторожным фундаментом данных, а не полной базой измеренных характеристик.
