# v0.3.1 — Excel Knowledge Import & Audit

Добавлены:

- Node-only XLSX reader на `exceljs@4.4.0`;
- workbook inspection: sheets, headers, rows, hidden state, formulas, errors, merges;
- raw и normalized staging для табаков, миксов и компонентов;
- per-fact provenance и confidence;
- разделение catalog facts, real observations, external ratings, tags и preliminary inference;
- exact identity mapping без fuzzy matching;
- отдельная identity производителя `НАШ` (`nash`) и manufacturer-only canonical IDs;
- проверка процентов, частей, граммов, total weight, orphan и duplicate candidates;
- immutable imported registry;
- typed deterministic audit report и JSON serialization;
- public privacy audit;
- synthetic workbook fixture, tests и verify с параметром пути.

Реальный workbook в Git не добавлен и во время реализации отсутствовал в workspace. Prisma schema, migration, PostgreSQL, seed, UI, Recommendation Engine, Compatibility Engine, scoring и Mix Analysis Service не изменены.
