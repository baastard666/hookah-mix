# v0.2.9 — Canonical Catalog Identity Persistence

Каталог `Flavor` расширен постоянной canonical identity. Добавлены безопасная Prisma migration, application-level типы, mapper результатов v0.2.8, стабильные resolved и manufacturer-only IDs, dry-run/apply backfill, защита verified-записей, `REAL/TEST/INTERNAL`, coverage report, транзакционный explicit update service, consistency verifier, тесты и документация.

Девять явно тестовых записей `Test Kitchen` помечаются seed как `TEST`. Registry не наполнен непроверенными производителями, линиями или техническими свойствами. Scoring, Mix Analysis Service, Recommendation Engine и UI не изменены; экспертная база миксов ещё не подключена.
