# v0.3.2 — Canonical Tobacco Catalog Expansion: release summary

## Назначение

Версия v0.3.2 добавляет детерминированный слой ручных решений для canonical tobacco identity поверх read-only импорта экспертного workbook. Решения применяются только по exact-normalized source identity и не меняют исходные данные, Prisma schema, UI или алгоритмы анализа миксов.

## Состав релиза

- immutable Tobacco Identity Decision Registry;
- один P1 batch и P0 batches 1–6;
- 96 versioned authoritative decisions с evidence и review metadata;
- 86 canonical products с ASCII-only `canonicalProductId`;
- 51 точный alias и 18 legacy mappings для совместимости прежних canonical ID;
- runtime validation, deterministic exact lookup и coverage comparison;
- audits canonical/transliteration/alias collisions, privacy и public-safe mapping;
- read-only real-workbook verification, unresolved report и P0/P1 review generation.

Все семь decision-модулей включены в aggregate Registry ровно один раз. Все 96 identity group IDs и 86 canonical product IDs уникальны. Registry содержит 86 `RESOLVED`, 7 `AMBIGUOUS`, 1 `MANUFACTURER_ONLY` и 2 `UNRESOLVED` решения.

## Ограничения

- В 208 exact source groups отсутствует product line; отсутствие линии само по себе не является доказательством конкретной линейки.
- Одинаковые или близкие названия могут существовать в разных линейках.
- При неоднозначности Registry не выбирает продукт автоматически и не использует fuzzy matching.
- Пользовательские и authoritative source data имеют приоритет над эвристикой.
- Decision layer пока не подключён к UI и не сохраняется в PostgreSQL.

## Privacy guarantees

Public-safe output не содержит имён авторов, внутренних заметок, source row IDs и source URLs. Дословные приватные цитаты не публикуются. Evidence и provenance хранятся только во внутреннем decision layer для трассировки и исключаются public mapper.
