# ADR-005: Диапазоны процентов в рекомендациях

## Status

Accepted

## Context

Без реальных тестов и пользовательских данных невозможно честно утверждать, что существует единственное идеальное процентное значение.

## Decision

Первая версия возвращает реалистичные диапазоны процентов и роль компонента. Suggested variant использует середину диапазона только как детерминированный пример перераспределения.

## Consequences

Результат не создаёт ложную точность и оставляет пространство для настройки. Точные оптимальные проценты могут появиться позднее на основе проверенных тестов и отзывов.
