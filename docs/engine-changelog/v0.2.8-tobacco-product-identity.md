# v0.2.8 — Tobacco Product Identity & Catalog Audit

Добавлен независимый детерминированный identity resolver с typed statuses, reason codes, безопасной Unicode-нормализацией, приоритетом явных полей и контролируемым prefix parsing только по публичным данным registry v0.2.7. Добавлены plain-object адаптер текущего каталога, read-only аудит, диагностика возможных дублей, JSON-вывод, 34 unit-теста и verify-скрипт.

Версия не меняет scoring, рекомендации, Mix Analysis Service, UI или каталог. Prisma schema, миграции и seed не изменялись. Аудит не исправляет и не объединяет записи автоматически.
