## Данные и evidence

- Заполнено 42 новых измерения, доведя суммарный итог по 60 продуктам до 208 заполненных измерений из 420 возможных (60 × 7) и 420 evidence-записей.
- Только batch 4: `overallConfidence` — `MEDIUM` у 8 продуктов (`overdose-coffee`, `overdose-strawberry`, `banger-apricot-jam`, `duft-solo-cherry-juice`, `duft-solo-orange-zest`, `endorphin-apple`, `endorphin-napoleon`, `fake-holod`), `LOW` у 7 (`sapphire-crown-mejumi`, `brusko-medium-tsitrusovyi-chai`, `husky-caipirinha`, `husky-marzipan`, `husky-passion-fruit`, `husky-pineapple`, `dozaj-mint`).
- `dozaj-mint` не получил ни одного заполненного измерения: поиск нашёл только материалы о вкусе «Mint» другого бренда (Rave Tobacco), ошибочно подмешанные в выдачу — они не использованы как evidence именно для Dozaj; `dominantNoteIds: ["MINT"]` взят из подтверждённого названия продукта.
- Отдельно зафиксирован риск ложной атрибуции: для `husky-passion-fruit` поиск вернул описания вкуса «Passion Fruit» нескольких других марок (Fumari, Serbetli, Spectrum, Bonche) — они намеренно не использованы; единственное значение (`sourness`) основано на отзыве, прямо относящемся к позиции Husky.
- Один случай прямого расхождения источников зафиксирован явно: для `brusko-medium-tsitrusovyi-chai` общее позиционирование бренда («средняя крепость») расходится со спецификацией конкретной позиции («с низкой крепостью») — сохранено с `LOW` confidence и пометкой расхождения, а не выбором одной стороны.
- `juiciness` заполнен только у `duft-solo-cherry-juice` («вкус сочный, более кислый, чем сладкий») — 1 из 15.
- `HIGH` confidence не использован ни разу.
