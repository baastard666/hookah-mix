# v0.3.0 — Expert Mix Knowledge Schema Foundation

Добавлен независимый typed domain module экспертных свидетельств:

- knowledge records, компоненты и статусы;
- percent, approximate percent, parts, order-only и unknown proportions;
- source, evidence, observations, preparation и evaluation;
- категориальный confidence и явный origin facts/interpretations;
- deterministic Unicode-safe IDs;
- runtime validation с typed errors/warnings;
- immutable read-only registry и стабильные filters;
- нейтральный external adapter boundary;
- public-safe mapper и privacy tests;
- 12 synthetic fixtures/cases, unit tests и verify script;
- architecture, ADR и roadmap.

Реальные миксы не импортированы. Prisma schema, seed, UI, scoring, Recommendation Engine, Compatibility Engine, Mix Analysis Service и технический Tobacco Profile Registry не изменены. Excel/CSV не подключены, имена авторов публично не раскрываются.
