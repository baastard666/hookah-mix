# v0.3.2 — P0 Tobacco Identity Decisions, batch 1

Первая ручная P0-партия выбрана из актуального `tobacco-identity-review-p0-p1.json` детерминированно: только P0, без уже подтверждённых решений, затем `verifiedMixCount`, `componentOccurrenceCount`, `occurrenceCount`, известность manufacturer/line и exact-normalized identity. Остальные 13 имели одинаковые показатели `1 / 1 / 2` и были выбраны по заданному exact-normalized алфавитному tie-break. `productLine` хранится отдельно от manufacturer: например, `manufacturer = Chabacco`, `productLine = Mix`, а не `Chabacco Mix`.

Итог review: 15 проверено, 15 `CONFIRMED`/`RESOLVED`, 0 `MANUFACTURER_ONLY`, 0 `UNRESOLVED`, 0 `AMBIGUOUS`, 0 `REJECTED`, 0 `NEEDS_MORE_EVIDENCE`. Канонические ID созданы существующим deterministic Unicode-safe builder. Исторические и сокращённые source names сохраняются как exact source identity или подтверждённый public-safe alias; исходные workbook-значения не меняются.

## Хранение и совместимость

- P0 data находится в `src/lib/tobacco-identity-decisions/p0-decisions-batch-1.ts`.
- Один authoritative aggregate `TOBACCO_IDENTITY_DECISION_REGISTRY` объединяет прежний P1 batch и новый P0 batch.
- Отдельный P0 registry не создан. Старый P1 batch export сохранён как backward-compatible проверочный API; его 20 решений не изменены.
- `MustHave / Ананас` остаётся `MANUFACTURER_ONLY`/`NEEDS_MORE_EVIDENCE` без canonical ID.
- `НАШ` и `Dogma` остаются разными; P2/P3 не применяются.
