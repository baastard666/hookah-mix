# ADR-004: Рекомендации поверх готового анализа

## Status

Accepted

## Context

Mix Profile и Compatibility Engine уже предоставляют профиль, влияние, предупреждения и конфликты. Повтор этих вычислений внутри рекомендаций создал бы расходящиеся источники истины.

## Decision

Recommendation Engine принимает готовые результаты анализа и связывает каждое действие с исходными `ruleId`, компонентами и knowledge claims. Он не меняет формулы профиля и совместимости.

## Consequences

Рекомендации прозрачны и воспроизводимы, но ограничены структурой данных текущих движков. Новые виды советов могут потребовать обратносуместимого расширения анализа.
