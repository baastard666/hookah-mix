# v0.3.5 — Product Flavor Profile Registry, добор измерений до 7-полевой модели (ADR-014)

## Цель

По ADR-014 целевая модель Product Flavor Profile Registry расширена с 4 до 7 измерений: добавлены `strength`, `heatResistance`, `juiciness`. По требованию — сначала добрать эти три измерения для уже покрытых 30 продуктов batch 1–2, и только потом начинать batch 3. Batch 3 в этой итерации не начинался.

## Методология

Та же схема evidence/confidence, что и раньше (`MANUFACTURER_CLAIM` / `REVIEW_AGGREGATE` / `EDITORIAL_ASSESSMENT`, confidence `LOW`/`MEDIUM`, без `HIGH`). Дополнительно введено явное различие по уровню атрибуции:

- **Уровень конкретного вкуса** (например, HTReviews «официальная крепость / пользовательская оценка» для конкретной позиции, либо прямая цитата ритейлера про именно этот вкус) — `MEDIUM` confidence.
- **Уровень бренда/линейки**, перенесённый на конкретный продукт без отдельного подтверждения именно для него — `LOW` confidence для `strength` (крепость может отличаться между конкретными вкусами одного бренда) и `MEDIUM` confidence для `heatResistance` (жаростойкость — свойство обработки листа/сиропа, как правило единое для всей линейки бренда, что отражено уже в `tobacco-profile`).

Для `BlackBurn` и `MustHave` бренд-уровневая жаростойкость и (частично) крепость переиспользованы из уже провалидированного модуля `src/lib/tobacco-profile/` (`https://www.blckburn.com/`, `https://hookahhouse.ru/catalog/tabak_dlya_kalyana/musthave/`) вместо повторного независимого поиска — сопоставление brand→manufacturerId проверено вручную по декларациям бренда в decision registry.

`juiciness` заполнен только там, где источник явно использует слово «сочный»/«juicy» применительно к конкретному вкусу (`overdose-apple-juicy`, `musthave-sour-citrus`, `musthave-blackberry`, `sapphire-crown-pineapple-fanta`, `blackburn-na-chille`) — 5 из 30 продуктов. Для остальных 25 юiciness оставлен незаполненным: наличие фруктовой ноты само по себе не считается доказательством сочности.

## Данные

- Заполнено 63 новых измерения (`strength` — 27 из 30 продуктов, `heatResistance` — 25 из 30, `juiciness` — 5 из 30); прежние `sweetness`/`sourness`/`freshness`/`intensity` не пересчитывались.
- Итог по всем 30 продуктам: 113 заполненных измерений из 210 возможных (30 × 7), 230 evidence-записей.
- `overallConfidence` пересчитан по правилу «не выше минимального среди заполненных» для всех 30 продуктов: часть продуктов понижена с `MEDIUM` до `LOW` из-за добавленной низкоуверенной бренд-уровневой крепости (например, `musthave-blackberry`, `blackburn-tic-tac`, `blackburn-ice-baby`, `musthave-sour-tropic`, `musthave-sour-citrus`, `deus-skittles`, `hook-limon-laim`, обе позиции Sapphire Crown с htreviews-крепостью); два продукта, ранее не имевшие ни одного измерения (`urban-soul-pineapple`, `husky-kiwano`), впервые получили `overallConfidence: MEDIUM` вместо прежнего `LOW`, так как их новые измерения confirmed на уровне `MEDIUM`.
- Confidence breakdown по 30 продуктам: `LOW` — 22, `MEDIUM` — 8, `HIGH` — 0 (было `LOW` 15 / `MEDIUM` 15 до добора).

## Тесты и проверки

- Обновлены тесты sparse-кейсов: `jam-spelaya-marakuiya`, `blackburn-almond-pear`, `husky-kiwano` больше не имеют пустого `dimensions` (у них теперь `strength`/`heatResistance`) — тесты проверяют точный набор присутствующих ключей вместо `{}`.
- Полный Vitest: **956/956 passed, 29 files** (без изменения количества тестов — обновлены существующие проверки под новые данные, новых файлов тестов не добавлено).
- `tsc --noEmit`: без ошибок. `eslint .`: без замечаний.
- `verify:product-flavor-profile`: 30 продуктов, 113 заполненных измерений, 230 evidence, confidence LOW/MEDIUM/HIGH = 22/8/0.
- Prisma schema, миграции, существующие engines и `TobaccoIdentityDecision`-записи не изменены.

## Ограничения

- Batch 3 (продукты 31+) не начинался в этой сессии — по прямому требованию.
- Для двух производителей (Hook, Husky) `heatResistance` не заполнен ни для одного продукта — источников не найдено.
- Часть бренд-уровневых заявлений о крепости/жаростойкости противоречат друг другу между источниками (Deus) — отражено пониженным `LOW` confidence и явной пометкой расхождения в evidence.
- `juiciness` остаётся самым редко заполняемым из 7 измерений (5 из 30) — это ожидаемо: большинство обзоров вкуса не используют слово «сочный» явно, а домысливать сочность по типу ноты (фрукт/ягода) означало бы угадывание.
