# Engine null-data correctness

## Исправление

`profile.flat` в Compatibility Engine больше не считает профиль «плоским», когда
набор измеренных sensory-значений пуст. Причиной была семантика JavaScript:
`[].every(...)` возвращает `true`.

Правило теперь применяется только если измерены все семь характеристик, на
которых оно основано: сладость, кислотность, горечь, сливочность, охлаждение,
свежесть и сочность. Частично измеренный набор также не позволяет делать общий
вывод о плоскости профиля: неизвестное не является низким значением.

## Null-аудит

Проверены `mix-profile`, `mix-compatibility`, `canonical-mix-scoring`,
`mix-recommendation` и presentation/risk mapping. Других правил, которые
срабатывают только из-за пустого набора sensory-измерений, не обнаружено.
Существующий fallback интенсивности и calibration/weights не менялись.

## Отдельный finding — confirmations

При отсутствии независимых подтверждений текущая ось `confirmations` показывает
baseline `5`. Это может быть неверно понято как пять фактических подтверждений.
Исправление не входит в этот патч: baseline, формула confidence и scoring
calibration сохранены для отдельной итерации Gold Set / scoring calibration.
