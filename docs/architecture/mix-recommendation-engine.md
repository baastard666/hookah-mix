# Mix Recommendation Engine

## Назначение

Recommendation Engine строит объяснимые действия поверх уже рассчитанных `MixProfileResult` и `MixCompatibilityResult`. Он не пересчитывает профиль, не ищет конфликты заново и не оценивает, понравится ли вкус пользователю.

## Вход и выход

Вход содержит исходные компоненты с процентами, числовыми профилями и нотами, готовый профиль микса и готовый результат совместимости. Выход содержит статус, до пяти ранжированных рекомендаций, структурированные reason codes и максимум один `SuggestedMixVariant`.

Типы действий: уменьшить, увеличить или удалить компонент, перераспределить базы, добавить направление ноты, снизить перегрузку профиля, сохранить микс либо сообщить о недостаточных данных.

## Диапазоны процентов

Движок возвращает диапазон, а не единственное «идеальное» значение. Границы зависят от текущей доли, интенсивности и предполагаемой роли. Яркий цветочный компонент может перейти в `ACCENT` с диапазоном 5–15%, а слабый компонент 3% — в диапазон 8–15%.

## Suggested variant

Вариант строится только по самой приоритетной применимой рекомендации. Для выбранного компонента берётся середина предложенного диапазона, а разница детерминированно распределяется между остальными компонентами пропорционально их текущим долям. Все значения остаются положительными, итог нормализуется до 100%. Если безопасная нормализация невозможна, вариант не возвращается.

## Compatibility и Knowledge Layer

Рекомендации ссылаются на существующие warning/conflict `ruleId`. Knowledge Layer используется только через публичный API: проверяет отношения добавляемой категории с текущим профилем, исключает `RISKY`/`CONFLICT` направления и предоставляет claim confidence.

## Confidence

Confidence рекомендации учитывает наличие исходного ruleId, confidence компонента, однозначность источника и confidence связанных knowledge claims. Это качество обоснования действия, а не прогноз пользовательских предпочтений.

## Ограничения

- Движок не подключён к UI и ничего не сохраняет.
- Нет симуляции повторного профиля после изменения процентов.
- Возвращается максимум один вариант и нет альтернативных веток.
- Рекомендуются категории, а не конкретные продукты.
- Нет отзывов, статистической оптимизации, ИИ и внешних API.
