# ADR-003: Evidence и confidence

## Status

Accepted

## Context

Категориальные и вкусовые утверждения имеют разную надёжность. Без происхождения знания невозможно объяснить, почему правило существует и насколько ему можно доверять.

## Decision

Knowledge claims ссылаются на evidence. Confidence рассчитывается из независимых источников, их весов, разнообразия типов и наличия проверенного теста. Дубли одного источника не усиливают результат искусственно.

## Consequences

Система может объяснить качество подтверждения правила. Confidence не является пользовательской оценкой, характеристикой вкуса или `compatibilityScore`; небольшой registry пока использует демонстрационные evidence.
