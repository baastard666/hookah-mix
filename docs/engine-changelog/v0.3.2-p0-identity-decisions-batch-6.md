# v0.3.2 — P0 Tobacco Identity Decision, batch 6

Финальный P0 batch содержит одну оставшуюся exact-normalized identity: `identity-group-0023 — Sebero / — / Черника`. Источник — один компонент `VERIFIED`-микса из `Mix_Components`; точные внутренние идентификаторы строки подтверждены локально и намеренно не публикуются. Catalog occurrence отсутствует.

## Проверенные варианты

- `Sebero Classic / Bilberry`: официальный дистрибьютор OSHISHA явно указывает название `Черника (Bilberry)`, линейку `Sebero Classic` и моновкус.
- `Sebero Limited Edition / Blueberry`: официальный канал Sebero анонсировал отдельный продукт `Limited Edition BLUEBERRY`; HTReviews связывает его с русским названием `Черника`.
- `Sebero Black / Blueberry`: профильные каталоги подтверждают отдельный продукт линии Black с русским названием `Голубика`.

Также проверены варианты `Bilberry`, `Blueberry` и `Черника`. Черничные напитки, йогурты, джемы, лесные ягоды и сложные профили не рассматривались как exact aliases.

## Решение

Итог: `AMBIGUOUS`, review state `AMBIGUOUS`, `ProductLineInterpretation=AMBIGUOUS`.

Исходная строка не содержит product line. Как минимум Classic/Bilberry и Limited Edition/Blueberry являются допустимыми точными кандидатами, а выбор по одному русскому слову нарушил бы exact-only contract. Поэтому:

- canonical product не создан;
- `canonicalProductId=null`;
- `productLineId=null`;
- aliases не добавлены;
- legacy mapping не добавлен;
- решение не применяется как product resolution.

Evidence: `OFFICIAL_SOCIAL_ANNOUNCEMENT`, `VERIFIED_RETAIL_CATALOG`, `VERIFIED_REVIEW_DATABASE`; confidence `HIGH/HIGH/MEDIUM`.
