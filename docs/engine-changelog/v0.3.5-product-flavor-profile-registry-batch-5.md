# v0.3.5 — Product Flavor Profile Registry, batch 5

## Цель

Пятый батч. Покрытие расширено с 60 до 75 из 86 `RESOLVED` продуктов — весь батч состоит из Tier 3 (нет производителей Tier 1/2 среди оставшихся 26 продуктов с primary-метриками `1/1/2`).

## Исправление в changelog batch 4

При построении очереди для batch 5 обнаружена и исправлена ошибка в служебном скрипте `scripts/tmp-batch4-queue.ts` (уже удалён после использования): сопоставление с отчётом `reports/tobacco-identity-review-p0-p1.json` шло по несуществующему полю `sourceGroupId` вместо реального `groupId`, из-за чего все кандидаты получали нулевые метрики. Это не повлияло на состав и порядок самих 15 продуктов batch 4 (внутри группы полной ничьей по primary-метрикам порядок определяется tier + `canonicalProductId`, что не зависит от того, были ли метрики 0 или их настоящие значения). Однако пострадала справочная фраза о том, какой продукт перейдёт в batch 5: в changelog batch 4 ошибочно указано `hook-granatovyi`, тогда как корректный следующий по очереди продукт — `fake-mumbai-tea` (алфавитно предшествует `hook-granatovyi` в той же группе Tier 3 с одинаковыми метриками). Строка в `docs/engine-changelog/v0.3.5-product-flavor-profile-registry-batch-4.md` исправлена.

## Данные и evidence

- Заполнено 35 новых измерений, доведя суммарный итог по 75 продуктам до 243 заполненных измерений из 525 возможных (75 × 7) и 490 evidence-записей.
- Только batch 5: `overallConfidence` — `MEDIUM` у 9 продуктов (`fake-mumbai-tea`, `hook-granatovyi`, `hook-inzhirnyi`, `jam-krasnaya-smorodina`, `mattpear-ginger-feel`, `nash-black-line-arbuz`, `peter-ralf-dolce-de-lechee`, `severnyi-krepkii-oreshek`, `take-pineapple`), `LOW` у 6 (`jam-granatovyi-sok`, `jam-konfety-s-ananasom`, `sarma-360-ogurechnyi-limonad`, `sarma-classic-bananovoe-sufle`, `severnyi-sekvoiya`, `smoke-angels-firestarter`).
- Явно зафиксирован риск кросс-брендового смешения источников и исключён: для `fake-mumbai-tea` поиск вернул также страницу вкуса «Mumbai Tea» бренда Chabacco (`htreviews.org/tobaccos/chabacco/.../mumbai-tea`) — это другой производитель с похожим названием вкуса; использована только страница именно бренда FAKE.
- Один случай явной неопределённости привязки к варианту линейки зафиксирован: для `sarma-360-ogurechnyi-limonad` найденный источник описывает конкретно вариант «Крепкая Сарма 360», тогда как canonical-решение не различает подварианты «Крепкая»/«Лёгкая» линейки 360 как отдельные продукты — значение `strength` сохранено с `LOW` confidence и явной пометкой этой неопределённости.
- Один случай отступления от стандартного правила «brand-level reuse → LOW» для `strength` обоснован явно: для `take-pineapple` источник напрямую утверждает, что вся линейка Take сделана по единой рецептуре с единой крепостью, где между вкусами меняется только ароматическая добавка — то есть отсутствует типичная причина понижать уверенность (крепость не варьируется между вкусами по построению). Значение `strength` сохранено с `MEDIUM` вместо стандартного `LOW` для brand-level reuse, с явным обоснованием в evidence.
- Полностью не найдено собственное текстовое описание вкуса для `take-pineapple` (не проиндексирован на HTReviews, отсутствует в доступных розничных карточках) — заполнен только `strength` на уровне бренда.
- `juiciness` не заполнен ни у одного из 15 продуктов batch 5 — ни в одном источнике не встретилось прямое слово «сочный»/«juicy».
- `HIGH` confidence не использован ни разу.
