# v0.3.5 — Product Flavor Profile Registry, batch 3

## Цель

Третий приоритетный батч. Покрытие расширено с 30 до 45 из 86 `RESOLVED` продуктов. Первый батч, отобранный с применённым manufacturer-tier tie-break (`src/lib/product-flavor-profile/priority-queue.ts`, введён вместе с ADR-014). Registry по-прежнему не подключён к `calculateMixAnalysis`, scoring или UI.

## Очередь приоритизации — фактический порядок

Среди 56 оставшихся `RESOLVED`-продуктов primary-метрики (`verifiedMixCount → componentOccurrenceCount → occurrenceCount`) дали массовую ничью: 46 из 56 кандидатов имели одинаковые `1/1/2`. Именно на этой ничьей и сработал новый tie-break: все 16 позиций Tier 1 (`Chabacco`, `Element`, `MustHave`, `Sapphire Crown`) оказались наверху этой группы, и первые 15 из них по возрастанию `canonicalProductId` составили batch 3 целиком:

1. `chabacco-medium-belgian-cider`
2. `chabacco-mix-apelsin-slivki`
3. `chabacco-mix-bananovyi-milksheik`
4. `chabacco-mix-fruktovyi-led`
5. `chabacco-mix-grenadin-drops`
6. `chabacco-moroznaya-myata`
7. `element-air-milky-mouse`
8. `musthave-maple-pecan`
9. `musthave-pineapple-rings`
10. `musthave-vanilla-cream`
11. `sapphire-crown-apple-strudel`
12. `sapphire-crown-blueberry-granola`
13. `sapphire-crown-fragrant-blackcurrant`
14. `sapphire-crown-kiwi-fruit`
15. `sapphire-crown-lemon-lime`

Шестая позиция Sapphire Crown (`sapphire-crown-mejumi`) осталась на ранге 16 и переходит в batch 4; Tier 2 (`Brusko`, `Husky`, `Overdose`) начинается с ранга 17. Очередь вычислена реальным `sortByPriorityQueue`/`comparePriorityQueueCandidates`, а не вручную.

## Данные и evidence

- Заполнено 53 новых измерения, доведя суммарный итог по 45 продуктам до 166 заполненных измерений из 315 возможных (45 × 7) и 336 evidence-записей.
- Только batch 3: 15 продуктов, `overallConfidence` — `MEDIUM` у 6 (все Chabacco-позиции, кроме одной без подтверждённой линии, плюс Element Air Milky Mouse), `LOW` у 9.
- Учтена специфика линеек Chabacco: `Chabacco Medium` (крепость средне-лёгкая, высокая жаростойкость) и `Chabacco Mix` (крепость лёгкая, жаростойкость низкая) имеют разные официальные технические спецификации — они не усреднялись и не смешивались. Для `chabacco-moroznaya-myata`, у которой decision explicitly `productLineId: null` (линия не подтверждена), использовано только общее заявление о жаростойкости бренда в целом, с явно пониженным `LOW` confidence, а не характеристика одной из линий.
- `juiciness` заполнен там, где источник прямо использует слово «сочный»/«juicy»: `element-air-milky-mouse` (сгущённое молоко), `musthave-pineapple-rings` (ананасовые кольца в собственном соку) — 2 из 15.
- Один случай прямого расхождения источников зафиксирован явно: для `chabacco-mix-fruktovyi-led` розничное описание указывает «крепость средняя», что расходится с официальной спецификацией линейки Mix («лёгкая»); сохранены оба значения раздельно (розничное — с `LOW` confidence и явной пометкой расхождения, спецификация линейки — как основа для остальных Mix-продуктов).
- `HIGH` confidence не использован ни разу.

## Тесты и проверки

- `product-flavor-profile.test.ts` дополнен проверками состава batch 3, отсутствия пересечений со всеми предыдущими батчами и суммарного размера registry (45).
- Полный Vitest: **957/957 passed, 29 files** (было 956/29 после добора batch 1–2; +1 тест — новая проверка состава batch 3).
- `tsc --noEmit`: без ошибок. `eslint .`: без замечаний.

- Prisma schema, миграции, существующие engines и `TobaccoIdentityDecision`-записи не изменены.

## Ограничения

- Покрыты 45 из 86 `RESOLVED` продуктов; остальные 41 — предмет следующих батчей (начиная с ранга 16, `sapphire-crown-mejumi`).
- Для линии Chabacco без подтверждённой productLine (`chabacco-moroznaya-myata`) `strength` не заполнен — общего надёжного заявления о крепости бренда в целом (в отличие от жаростойкости) не найдено, а линейные данные Medium/Mix для этого продукта неприменимы по построению identity decision.
