# ADR-009: постоянная каноническая идентичность каталога

## Context

Resolver v0.2.8 надёжно диагностирует каталог, но повторный разбор свободных строк при каждом анализе не является устойчивым источником идентичности. Будущим Flavor Profiles и базе экспертных миксов требуется стабильная ссылка на продукт.

## Decision

Расширить существующий `Flavor` nullable canonical-полями и application-level статусами. Сохранить технический primary key отдельно от globally unique nullable `canonicalProductId`. Registry IDs хранить как строки без SQL foreign keys, поскольку registry является статическим versioned источником, а не таблицей PostgreSQL.

Разрешить `productLineId=null` и статус `MANUFACTURER_ONLY`; линия никогда не угадывается. Формировать line-less ID через явный сегмент `manufacturer-only`. Неизвестному производителю ID не назначать.

Resolver использовать только для предложений. Mapper и backfill сохраняют результат, причём backfill по умолчанию dry-run, `--apply` транзакционен, а `identityVerified` автоматически не выставляется. Проверенные записи защищены. `Test Kitchen` отделить как `TEST` на основании явных доказательств в seed.

## Consequences

- идентичность стабильна между запусками и готова для будущих связей;
- display-поля и существующие связи не меняются;
- технические свойства не дублируются в Prisma;
- unknown и ambiguous данные остаются видимыми, а не угадываются;
- ручная проверка имеет явную защиту;
- coverage реального каталога не искажается тестовыми fixtures;
- изменение static registry требует consistency verification, а не SQL foreign key migration.

## Alternatives considered

- запускать resolver во время каждого анализа — нестабильно для будущих импортов и связей;
- создать отдельную дублирующую таблицу товаров — лишняя модель при подходящем `Flavor`;
- сделать `productLineId` обязательным — вынуждает придумывать линию;
- автоматически считать resolver доверенной проверкой — смешивает машинное предложение и человеческое подтверждение;
- автоматически объединять дубли — небезопасная потеря каталожных строк.
