# v0.3.2 — ASCII Canonical Product IDs

Canonical tobacco product IDs стандартизированы по ADR-013. Формат: `^[a-z0-9]+(?:-[a-z0-9]+)*$`. Центральный builder используется identity decisions, tobacco resolver и catalog identity. Display names, aliases, evidence, status, confidence, workbook, Prisma и UI не менялись.

## Правила

- Подтверждённое официальное английское canonical name имеет приоритет.
- Без него применяется детерминированная русская транслитерация, а не смысловой перевод.
- Collision, duplicate, conflict и cycle не разрешаются автоматически.
- Старые ID используются только для lookup/migration; public-safe output содержит новый ID.
- Coverage и набор applied decisions должны совпадать с baseline до смены представления ID.
